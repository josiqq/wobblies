# Security Policy

## Supported versions

Only the latest minor release line receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately through GitHub Security Advisories:

https://github.com/josiqq/wobblies/security/advisories/new

Include a description, the affected package and version, and steps to reproduce. You can expect an initial response within a few days, and we will coordinate a fix and disclosure with you.
