Pick the package that matches your platform.

## Core (any JavaScript runtime)

<Tabs syncKey="pkg">
  <TabItem label="pnpm">
    ```sh
    pnpm add @wobblies/core
    ```
  </TabItem>
  <TabItem label="npm">
    ```sh
    npm install @wobblies/core
    ```
  </TabItem>
  <TabItem label="yarn">
    ```sh
    yarn add @wobblies/core
    ```
  </TabItem>
</Tabs>

```ts
import "@wobblies/core/animations.css";
```

## Expo

Let Expo pick the `react-native-svg` version that matches your SDK, then install Wobblies.

<Tabs syncKey="pkg">
  <TabItem label="pnpm">
    ```sh
    npx expo install react-native-svg
    pnpm add @wobblies/react-native
    ```
  </TabItem>
  <TabItem label="npm">
    ```sh
    npx expo install react-native-svg
    npm install @wobblies/react-native
    ```
  </TabItem>
  <TabItem label="yarn">
    ```sh
    npx expo install react-native-svg
    yarn add @wobblies/react-native
    ```
  </TabItem>
</Tabs>

## Requirements

| Package | Peer requirements |
| --- | --- |
| `@wobblies/core` | None. Zero runtime dependencies. |
| `@wobblies/react` | `react >=18` |
| `@wobblies/react-native` | `react >=18`, `react-native >=0.72`, `react-native-svg >=13` |

All packages ship ESM, CommonJS and TypeScript types, and require Node 18 or newer.
