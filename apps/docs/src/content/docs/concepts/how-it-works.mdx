## Per-trait hashing

The normalized name is hashed once into a seed. Each trait (`shape`, `hue`, `tone`, `eyeGap`, and the finer geometry such as `body.pts` or `sun.n`) then gets its own value in [0, 1) from `hash(seed, traitKey)`.

Because every trait is hashed independently, adding a new trait never reshuffles the existing ones, and any trait can be overridden with `traits`:

```ts
import { createAvatar } from "@wobblies/core";

createAvatar("ana", { traits: { shape: "sun" } }); // always a sun, same colors
```

Numeric trait overrides (`hue`, `tone`, `eyeGap`, …) are numbers in [0, 1): non-finite values are ignored and the rest are clamped. `shape` takes a shape name (`"round"`, `"organic"`, `"boxy"`, `"nub"`, `"cloud"` or `"sun"`).

## Shapes

The `shape` trait is split into bands, so some shapes are more common than others:

| Shape | Probability |
| --- | --- |
| `round` | 26% |
| `organic` | 30% |
| `boxy` | 14% |
| `nub` | 13% |
| `cloud` | 10% |
| `sun` | 7% |

Each shape is scaled slightly so petals and nubs stay inside the canvas.

## Moods

A mood is a small set of offsets applied to the eyes and body.

| Mood | Eyes | Body |
| --- | --- | --- |
| `idle` | Natural. | Unchanged. |
| `happy` | Squinty, smiling arcs, tilted up. | Lifted slightly. |
| `sad` | Smaller, drooping, sloped outward. | Lowered. |
| `mad` | Narrow, sloped inward. | Tinted toward red, lowered slightly. |

## Render tree

`createAvatar` returns the SVG string and the same drawing as a tree of `nodes`. `@wobblies/react` and `@wobblies/react-native` turn that tree into elements directly, which is why neither parses XML or uses `dangerouslySetInnerHTML`.

<Aside>
All of this is covered by the [stability contract](/wobblies/concepts/stability/): a change to any of it changes the SVG. During 0.x that ships as a minor release flagged **Visual change:**; from `1.0.0` it needs a major version.
</Aside>
